Scroll Image Sequence - extracted frames

120 frames: frame_0001.webp … frame_0120.webp (in scroll order), ~1920px wide.

These were generated entirely in your browser and were NOT uploaded to ScrollTell -
you host them, so you own and control the assets.

To use them in the "Scroll Image Sequence" pattern:
  1. Upload these images to your own CDN / bucket / static host (keep the filenames).
  2. In the editor open the "URL pattern" tab and enter:
        https://YOUR-HOST/path/frame_{n}.webp
     Count = 120, Zero-pad = 4, Start # = 1.
     (Or use the "Paste list" tab and paste the full URLs, one per line.)
